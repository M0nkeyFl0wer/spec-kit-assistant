# Guide: unlock

The user has chosen to open code edits for this session before the to-do list exists. Typing this command already did it. It lasts until this session ends.

Say in one or two lines that edits are open for this session, that the earlier steps are being skipped by their choice, and that the plan is still there when they want it. Then do what they asked.

This command is for the user to type. If you are reading this because you invoked it yourself, stop: you must not unlock on the user's behalf, and invoking it this way has no effect.
